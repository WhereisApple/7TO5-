Syntax

Learn 7TO5

7TO5 is a compact programming language designed to teach the essentials of variables, arithmetic, logic, loops, and functions using readable syntax.

Variables

let num A be 10
let str name be "Ava"
let deci price be 19.99

Math

let num total be add A and B
let num diff be sub A and B
let num result be mul total and 2

Logic

if score gt 10 then {
  print "Pass"
} else {
  print "Retry"
} end

Loops

while count lt 5 do {
  print count
  set count = add count and 1
} end

Functions

func addOne(num x) {
  return add x and 1
} end

print call addOne(10)

Output

print "Welcome to 7TO5"
print total

Reference

  • let declares a variable
  • set updates an existing variable
  • print shows output
  • if ... then ... else ... end handles conditions
  • while ... do ... end loops code
  • func defines a function
  • return returns a value
  • call calls a function
